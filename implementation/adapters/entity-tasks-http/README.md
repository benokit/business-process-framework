# entity-tasks-http

`POST /entities/:entityType/:businessKey/task/answer` with `{ outcome, result? }` → `run` of the operation `answer` of the trait `task` of the entity type ([entity-tasks](../../entity/entity-tasks/README.md)), which must have it (`invalid` otherwise) → the record, with its revision as `ETag`. `If-Match` is required, as in [entity-states-http](../entity-states-http/README.md). The answer closes nothing: the process that asked for the task does. The [operation](../../services/authorization/README.md) is `{ area: "tasks", resource: <entityType>, action: "answer" }`; the actor `entity-task-worker-actor` grants the area. A grant per outcome is not possible yet (the outcome is data, not a closed set the authorization knows), and no route for `claim` exists yet.
