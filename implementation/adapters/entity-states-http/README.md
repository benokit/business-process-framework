# entity-states-http

`POST /entities/:entityType/:businessKey/transitions/:transition` → `run` of the operation `transition` of the trait `state` of the entity type ([entity-states](../../entity/entity-states/README.md)), which the entity must have (`invalid` otherwise) → the record, with its revision as `ETag`. `If-Match` is required; the ETag conventions are those of [entities-http](../entities-http/README.md). The [operation](../../services/authorization/README.md) is `{ area: "states", resource: <entityType>, action: <transition> }`; actor `entity-lifecycle-actor` (area `states`, except the resource `user`).
